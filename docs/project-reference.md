# Project reference

Fast Recipes investigates the cost of server-side crafting, recipe selection
and cooking in Minecraft. Fabric Loader is the sole required mod dependency. Fabric API is optional.

| Input | Local target |
| --- | --- |
| Minecraft Java | 26.3 |
| Game distribution | Unobfuscated dedicated-server classes |
| Fabric Loader | 0.20.1 is the build and test baseline |
| Fabric Loom | 1.18.4 |
| Gradle wrapper | 9.9.0 |
| Java | 25 |
| Mod ID | `fast_recipes` |
| Version | `0.1.0-alpha.2` |
| License | Apache-2.0 |

The [reference lock](references.lock.json) records source and artifact
fingerprints. Build inputs are configured in [gradle.properties](../gradle.properties).
Commands for the local workspace are in [verification](verification.md).
