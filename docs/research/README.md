# Research status

Minecraft 26.3, Fabric Loader 0.20.1 and Java 25 are the local development
baseline. The preferred outcome is an independent server-only mod, gated on
vanilla semantics and practical performance.

| [R-003 Comparative audit](R-003-comparative-audit.md) | Initial source comparison, runtime comparisons pending |
| [R-004 Baseline](R-004-baseline.md) | Two isolated runs, dedicated-server baselines and JFR diagnosis |
| [R-005 Experiments](R-005-experiments.md) | Separate runtime experiment and counterbalanced timing pilot |
| [R-006 Decision](R-006-decision.md) | Production promotion deferred pending broader correctness and ordinary-pack evidence |
